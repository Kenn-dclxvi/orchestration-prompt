# THE-CAPTION オーバーレイ

このオーバーレイは、汎用プロンプトセットを `THE-CAPTION-DEV` に展開するときの固有差分を保持する。

## 適用順

1. 共通ファイルを対象リポジトリへ配置する。
2. `overlays/the-caption/files/` の内容を、標準構成と同じ対象リポジトリ相対パスとして上書き配置する。

## 管理方針

- 共通化できる制御はリポジトリ直下の `AGENTS.md`、`prompts/`、`docs/` に戻す。
- THE-CAPTION 固有の正本文書、PR 言語規約、監査参照先はこのオーバーレイに残す。
- `files/` 配下は展開後の現在形を保持し、共通ファイルとの差分確認に使う。
