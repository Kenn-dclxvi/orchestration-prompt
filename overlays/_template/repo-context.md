# リポジトリコンテキスト雛形

このファイルは、適用先固有情報をオーバーレイに隔離するための空欄雛形である。`<...>` を対象リポジトリの固有値に置き換えて使う。用語の意味は `docs/glossary.md` を参照する。

## 対象
- リポジトリ: `<リポジトリ名>`
- 主要言語: `<主要言語>`
- 主要ルート: `<主要ディレクトリ>`

## 参照文書
- 概要: `<概要文書のパス>`
- アーキテクチャ: `<アーキテクチャ文書のパス>`
- ドメインルール: `<ドメインルール文書のパス>`
- テストガイド: `<テストガイド文書のパス>`

## 変更境界の扱い
- 実装指示書に対象ファイル、範囲、完了条件が明示されている場合だけ実装SAを起動する。
- 関連仕様は、指示書または親エージェントの作業単位で明示された場合だけ監査SAへ渡す。
- 固有コマンドは、作業単位の `tests` に明示された場合だけ実行する。

## 出力言語
- ユーザーとの会話で使われている主要言語に合わせる。
- PR テンプレートがある場合は、適用先のテンプレート構成を優先する。
